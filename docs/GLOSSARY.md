# BuildBond glossary

- **Milestone**: An ordered piece of work with its own amount and proof.
- **Proof**: A URL and note submitted by a contractor for a milestone.
- **Ledger**: Append-only deposit and release records used to derive balances.
- **Dispute**: A participant-raised freeze that stops proof and money actions.
- **Held balance**: Deposited amount minus released amount, in paise.
- **Paise**: The integer currency unit used by the application; 100 paise is
  one rupee.
