# BuildBond reading guide

Read the project in this order:

1. `README.md` for the product behavior and API contract.
2. `server/db/schema.sql` for the data model and database constraints.
3. `server/src/domain.js` for statuses and state transitions.
4. `server/src/routes/` for request-level workflows.
5. `web/src/pages/` and `web/src/components/` for the user experience.
